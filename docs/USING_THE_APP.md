# Using the app

A quick tour. The full guide is built into the app: click the book icon at the top right. Its
chapters live in `src/lib/server/user-guide/chapters/`.

## The windows

| Window               | Use it to                                    |
| -------------------- | -------------------------------------------- |
| **Document Library** | Add, organize and switch documents on or off |
| **Chat History**     | Reopen, rename or delete past chats          |
| **Assistant Chat**   | Ask questions                                |
| **Search Context**   | Search your documents yourself               |
| **Notebook**         | Write notes and keep answers                 |

Drag windows between the two columns, and save different arrangements as tabs at the top.

## First answer in seven steps

1. **Get a model.** Click the model name in the chat box and download a local model.
2. **Add a document.** In the Document Library, click **Add to corpus → Add files**.
3. **Wait** for the progress bar to finish.
4. **Search.** Type in Search Context and press **Enter**.
5. **Ask.** Type a question in the chat and press **Enter**.
6. **Check the source.** Click **Open source** under the answer.
7. **Keep it.** Create a notebook, then click **Send to notebook** under the answer.

## Worth knowing

- Only **active** documents are searched. Use a document's power button to switch it.
- Mark a document **local only** and only the built-in local models will ever see it.
- Type **/** in the chat to run one of your skills.
- Everything saves automatically. There's no save button.
