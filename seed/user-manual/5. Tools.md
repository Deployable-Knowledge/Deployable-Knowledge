# 5. Tools

Tools let the assistant do things during an answer instead of just writing text, such as searching your documents several times or running a calculation. Tools are set up in **Settings → Tools**.

## What's in Settings

Open **Settings** with the gear icon at the far right of the top toolbar.
- **Left side:** a **Search settings** box, then the sections **Agent**, **Tools**, **Models**, **Embeddings**, **Appearance** and **Diagnostics**.
- **Right side:** the settings of the section you picked.

## What's in Settings → Tools

From top to bottom:
1. **Agent turns** (slider): how many rounds of tool calls the model can make before it must answer. It goes from 1 to **Unlimited**; the default is 6.
2. **Warning** (only if your model can't use tools): "The selected model doesn't support tool calls…". Pick a different model to use tools.
3. **The tools**: each has a checkbox, its name and a short description. Tick a tool to allow it, untick it to block it.

| Tool | What it does | Try asking |
|---|---|---|
| **Corpus details** | Lists the documents in your library | "Which documents do I have about safety?" |
| **Date & time** | Checks today's date instead of guessing | "How many days until the deadline?" |
| **Goal tracking** (off by default) | Keeps a checklist for long, multi-step requests | "Summarize each chapter, then write a conclusion." |
| **Python** | Runs calculations and draws charts using Python libraries; can read your CSV and text files | "Chart the monthly totals in sales.csv." |
| **Read document chunks** | Reads the text around a passage it found | "Read the section before that quote." |
| **Document search** | Searches your documents as many times as it needs | "Compare what these reports say about costs." |

## What you see in the chat

- Every tool call appears as a row above the answer, such as "Searching …" or "Ran Python". Click it to see exactly what was sent and what came back.
- Charts made with Python appear as images in the answer.
- With **Goal tracking** on, a **Goals** bar appears at the top of the chat showing progress.
- When tools were used, the answer's footer shows how many tools, context passages and turns were used.

## How to

**Turn tools on**
1. Pick a model that supports tools. If it doesn't, **Tools** is greyed out with "Not supported by this model".
2. In the chat box, open **Chat modes** and tick **Tools**.

**Choose which tools are allowed**
1. Open **Settings → Tools**.
2. Tick or untick each tool. Your choices are saved to your current profile.
