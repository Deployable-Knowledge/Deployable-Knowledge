# 6. Models

The **model** is the AI that writes the answers. You choose it from the **model picker** in the chat box, and download or connect models in **Settings → Models**.

## What's in the model picker

The model picker is at the bottom right of the chat box. The button shows the current model's name, or **Select a model** if none is chosen yet. While a model downloads, it also shows the download percentage.

Click it to open the list. From top to bottom:
1. **Local models**: models that run inside the app, fully offline.
   - A downloaded model: click it to use it.
   - A model not downloaded yet: shows "Needs ~8 GiB RAM" and a download icon. Click it to start the download.
   - A model downloading: shows "Downloading… 40%" and a progress bar.
2. **Other groups**, such as **Ollama** or a provider you've added. A group only appears when it has at least one model.
3. **Manage models** (gear icon): opens **Settings → Models**.

## What's in Settings → Models

From top to bottom:

**Local models**

One card for each built-in model. Each card shows, top to bottom:
1. The model's name, with an **Active** badge if it's the one in use.
2. Who made it and a link to its license.
3. A short description and how much memory it needs ("Needs ~8 GiB RAM").
4. Buttons: **Download** if it isn't downloaded yet, a progress bar while it downloads, or **Use this model** and **Delete** once it's on your computer.

| Model | Memory needed |
|---|---|
| **Gemma 4 E2B** | about 8 GB |
| **Gemma 4 E4B** | about 16 GB |
| **Gemma 4 26B A4B** | about 32 GB; for high-end computers with a dedicated graphics card |

**Local runtime** (only shown while a local model is in use)
1. **Compute device**: **Auto (recommended)**, **CPU only**, or your graphics card (**CUDA** or **Vulkan**) if you have one.

**Providers**
1. One row for each online or self-hosted service you've added: its name, web address, whether an API key is saved, and how many models it offers. On the right, **Edit** (pencil) and **Remove** (trash).
2. **Add provider** (+): connects a new service.

## How to

**Download a local model**
1. Open **Settings → Models**, or click **Manage models** at the bottom of the model picker.
2. Under **Local models**, click **Download** on a model your computer has enough memory for.
3. When the download finishes, click **Use this model**.

Only one download can run at a time. To free up space, click **Delete** on a downloaded model; you can download it again later.

**Switch models**
1. Click the model's name at the bottom right of the chat box.
2. Click the model you want.

You can also switch in **Settings → Agent → Provider and model**.

**Add an online or self-hosted provider**
1. Open **Settings → Models** and click **Add provider**, then **OpenAI-compatible**.
2. Enter a **Name**, the **Base URL** (including `/v1`), and an **API key** if the service needs one.
3. Click **Add provider**. Its models appear in the model picker.

## Ollama models (optional)
> **Only relevant if you already use Ollama.** If you don't know what Ollama is, skip this section: the **Local models** above do the same job without installing anything else.

Ollama is a separate, free program that runs AI models on your computer. Deployable Knowledge can use the models it has installed, but **Ollama must be installed and running on the same computer** for them to appear.

1. Install Ollama from [ollama.com/download](https://ollama.com/download) and start it.
2. Download a model in a terminal, for example `ollama pull gemma4:e4b`.
3. Open the model picker in **Assistant Chat**. The model appears in the **Ollama** group. If there is no Ollama group, Ollama isn't running or has no models yet.

Good to know:
- Ollama models run on your computer and work offline once downloaded. Models with `cloud` in their name are the exception: they run on Ollama's servers and need an internet connection.
- New models are always downloaded through Ollama itself; the app can't download them for you.
- Close Ollama and its models disappear from the picker until you start it again.
- If a model can't use tools, the **Tools** button in the chat box is greyed out.

## Profiles
A **profile** (**Settings → Agent → Profile**) saves your model, prompt, generation and retrieval choices together. Create one per task, for example "Quick answers" and "Deep research", and switch between them.
