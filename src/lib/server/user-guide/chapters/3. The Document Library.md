# 3. The Document Library

The **Document Library** window holds every document the assistant can read: files you add, folders you sync and text you paste in.

When you add a document, the app reads its text and cuts it into short passages called **chunks** (a few paragraphs each). When you ask a question, the assistant searches these chunks rather than whole documents, so a document must finish loading before the assistant can use it.

> **Your original files are safe.** The app keeps its own copy of everything you add. Removing a document from the library never deletes the file on your computer.

## What's in the window

**Finding documents**
1. **Filter box** ("Filter documents by name & tags…"): type to show only documents whose name or tags contain your words. With several words, a document must match all of them. The **X** at the end clears the box.
2. **Filter** (funnel icon): opens the tag menu. Click tags to show only documents that have **any** of them; the chosen tags appear as chips under the filter box, and clicking a chip's **X** removes it from the filter. This menu is also where you create and delete tags.
3. **Sort** (up/down arrows): **A → Z**, **Z → A**, **Newest** (the default), **Oldest**, **Most chunks** or **Least chunks**. The number of chunks is a rough measure of a document's length.

**Showing and managing all documents**
1. **All / Active in RAG / Inactive**: show every document, only the active ones (the ones the assistant searches), or only the inactive ones.
2. **Deactivate all** (power icon): switches every document off, so the assistant searches nothing until you switch some back on. Nothing is deleted.
3. **Remove all** (red trash icon): removes every document from the library. It asks first, and cannot be undone.

**Working with selected documents**
1. "N selected" shows how many documents are ticked.
2. When at least one document is ticked, a bar appears with **Apply tag**, **Remove tag**, **Activate**, **Deactivate**, **Local only** and **Allow all**. Each one acts on all ticked documents at once.

**Adding documents**
1. **Add to corpus** (+): opens a menu with **Add files**, **Sync folder** and **Add text**, and at the bottom an **Add as local only** checkbox. It is unavailable while files are loading or a folder is syncing.

**Document groups**

Documents are grouped: one group for each synced folder, plus **Individual files** (added with **Add files**) and **Manually Loaded** (pasted text). Each group's header shows, left to right:
1. **Checkbox**: selects every document in the group, for example to deactivate a whole folder at once.
2. The group's icon and name, its number of documents, and for folders the sync status:
   - **watching**: changes in the folder are picked up within seconds.
   - **synced**: the folder is checked for changes every 5 minutes.
   - **syncing**: a check is running now.
   - **reconnect needed**: the app has lost permission to the folder; click **Reconnect**.
   - **sync error**: the last check failed; the error is shown in red under the header.
3. **Autotag** (magic wand): tags every document in the group automatically (see **Autotag** below).
4. Folder groups only:
   - **Retry malformed files** (red arrow): only shown if some files failed to load. The app won't try those files again until they change, or until you click this.
   - **Reconnect** (plug): only shown if the app has lost access to the folder, for example because it was moved or permission was withdrawn. Click it and allow access again.
   - **Sync now** (circular arrows): checks the folder for changes immediately.
   - **Stop watching** (folder with an X): stops syncing but keeps the documents in the library.
   - **Remove folder and its documents** (trash): stops syncing and removes the folder's documents from the library. The folder and files on your computer are not touched.
5. **Collapse / Expand** (arrow): hides or shows the group's documents.

Long groups load more documents as you scroll ("Showing 50 of 120 documents").

**Each document**
1. **Checkbox**: selects the document, so the action bar above can act on it.
2. **Type icon**: document, spreadsheet or audio.
3. **Title**: click it to open the original document (see **7. Viewing the Original Source**).
4. **Number of chunks**, followed by "· inactive" when the document is deactivated and "· local only" when it is kept local only.
5. **Power button**: the icon shows what clicking it will do. On an active document it reads **Deactivate**; on an inactive one it reads **Activate**. An inactive document stays in the library but is never searched by the chat or by Search Context.
6. **Cloud button**: a plain cloud means every model can use the document; a crossed-out cloud means it is kept local only. Click it to switch (see **Keep documents local only** below).
7. **Autotag** (magic wand): tags this document automatically.
8. **Remove** (trash): removes the document from the library.
9. Under the title: the document's tags (click a tag's **X** to take it off this document), and a small **+** to add one.

A file that is still loading shows **Queued**, then a progress bar. "OCR page 3 of 10" means the app is reading text from images or scanned pages; "Embedding 12 of 40 chunks" means it is preparing the chunks for search. Large PDFs and audio files can take several minutes.

## What you can add

| Kind | File types | Notes |
|---|---|---|
| PDF | .pdf | Images and scanned pages are read with OCR (English) |
| Word, PowerPoint | .docx, .pptx | Converted to PDF automatically, which takes a moment |
| Spreadsheets | .xlsx, .csv | CSV files are found by keyword search only (see **5. Search Context**) |
| Text | .txt, .md, .markdown | |
| Audio | .mp3, .wav, .m4a, .flac, .ogg, .opus, .aac, .aiff, .webm, .wma | Transcribed on your computer (English, up to 100 MB / 2 hours) |

> **Good to know:** standalone image files (.png, .jpg) can't be added. Adding the exact same file twice does not create a duplicate.

## Add files, Sync folder or Add text?

| Use | When |
|---|---|
| **Add files** | You have a few specific files. Each is added once; later changes to the file on your computer are not picked up. |
| **Sync folder** | You want a whole folder, including its subfolders, and want the library to follow it as you add, edit or delete files. |
| **Add text** | The text isn't in a file: an email, a web page excerpt, meeting notes. Markdown formatting is kept. |
| **Add as local only** | The document is confidential, such as patient records or an unreleased contract, and you also use an online model. Tick this box before **Add files** or **Add text**, and only Local models will ever see the document. See **Keep documents local only** below. |

## How to

**Add files**
1. Click **Add to corpus**, then **Add files**.
2. Select one or more files. Hold **Ctrl** (or **Cmd** on a Mac) to pick several, or **Shift** to pick a range.
3. Wait for each progress bar to finish. The file then appears in **Individual files** and is ready to use.

**Add files** picks files only, not folders. To add everything in a folder, use **Sync folder**.

**Add pasted text**
1. Click **Add to corpus**, then **Add text**.
2. Enter a **Title** (up to 200 characters), paste the **Text**, and click **Embed text**. It appears in **Manually Loaded**.

**Sync a folder**
1. Click **Add to corpus**, then **Sync folder**, and choose a folder. Subfolders are included; hidden files are skipped.
2. The folder gets its own group and its supported files are loaded straight away.
3. From then on the library follows the folder:
   - **New or edited files** are loaded again automatically.
   - **Renamed or moved files** are recognized and not loaded twice.
   - **Deleted files** are removed from the library.
   - **Files that fail to load** are marked malformed, and a red **Retry malformed files** button appears on the group.

> **Good to know:** **Sync folder** works in the desktop app, Chrome and Edge. Removing a synced document inside the app makes the app ignore that file from then on, until you stop watching the folder.

**Activate or deactivate documents**

Only **active** documents are searched. Deactivate a document when you want the assistant and Search Context to ignore it without removing it, for example an old version of a report. It stays in the library, marked "· inactive", and you can activate it again at any time.
- **One document:** click its power button. On an active document it deactivates it; on an inactive one it activates it.
- **Several documents:** tick the checkbox of each document, or a group's checkbox to select the whole group. In the action bar that appears, click **Activate** or **Deactivate**.
- **Every document:** click **Deactivate all** (power icon) above the list.

**Keep documents local only**

Mark a document **local only** to keep its contents off the internet, for example a confidential report or personal records. A local-only document is only ever given to **Local models**, the models that run inside the app (see **8. Settings**). Ollama models and providers you've added never see it, even when they run on your computer.
- **While adding:** open **Add to corpus**, tick **Add as local only**, then choose **Add files** or **Add text**. The box stays ticked for everything you add until you untick it.
- **One document:** click its cloud button. A crossed-out cloud and "· local only" show the document is kept local; click it again to allow all models.
- **Several documents:** tick them, or a group's checkbox, and click **Local only** or **Allow all** in the action bar.

What changes for a local-only document:
- **Chatting with a Local model:** works as usual. But if an active local-only document is among the documents the chat searches, that chat becomes local only too and can only continue with a Local model. Picking another model then shows "This chat used local-only documents…"; start a new chat instead.
- **Chatting with any other model:** the assistant can't search, read or list local-only documents, and notebook sources that come from them are left out. Its answers draw only on your other documents.
- **Search Context:** still finds local-only documents, because the search runs on your computer.
- **Embedding:** local-only documents are only embedded by a **Local embedding model** (see **8. Settings**). With any other embedding model, Semantic search can't find them until you switch back; Keyword search still can.

> **Good to know:** **Add as local only** doesn't apply to **Sync folder**: a synced folder's files are added for all models. To keep them local, tick the group's checkbox and click **Local only**. Files marked this way stay local when edited, but files added to the folder later are not, so mark those too.

**Tag documents**

Tags are labels such as `budget` or `2025` that help you filter a large library.
1. Click **Filter**, type a **New tag** and click **Add**. Tags can use letters, numbers, dashes and underscores.
2. Tick the documents, click **Apply tag** and choose the tag. Or click the small **+** under one document.
3. To take a tag off, click the **X** on it under the document, or tick documents and use **Remove tag**.
4. To delete a tag from every document, click the **X** on it in the **Filter** menu.

**Autotag**

Autotag reads a document and adds the tags you've already created that fit its content, up to 5 per document. It never invents new tags, so create your tags first. If nothing fits well, it adds nothing.
1. Click the magic wand on a document, or on a group's header to tag the whole group.
2. A progress window shows each document as "tagged" or "no new tags".

**Remove documents**
- One document: click its trash icon and confirm.
- A synced folder's documents: click **Remove folder and its documents** on the group header and confirm.
- Everything: click **Remove all** and confirm. This cannot be undone.

In every case the files on your computer are not touched.
