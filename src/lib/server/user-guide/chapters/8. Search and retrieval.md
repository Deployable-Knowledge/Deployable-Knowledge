# 8. Search and retrieval

## How the assistant finds information
When a document is added it is cut into short passages called **chunks** (up to about 1,200 characters each). When you ask a question, the app finds the most relevant chunks and gives only those to the model. This is called **retrieval**.

Only **active** documents are searched. A document you switch off with its power button in the Document Library is ignored until you switch it back on (see **3. The Document Library**).

## The three retrieval methods

| Method | How it works | Best for |
|---|---|---|
| **Lexical** | Matches the exact words you typed (keyword search) | Names, codes, part numbers, exact phrases |
| **Semantic** | Matches meaning, even when the wording is different | Questions in your own words, concepts |
| **Hybrid** (default) | Runs both, then a second model re-ranks the combined results by how well each passage answers the question | Almost everything; the best starting point |

> **Good to know:** CSV files are only found by Lexical search, or the keyword half of Hybrid.

## What's in Settings → Agent → Retrieval

From top to bottom:
1. **Semantic / Lexical / Hybrid**: the method the chat uses.
2. **Retrieved chunks**: how many passages are given to the model with each question (default 5, up to 20 in chat).

More chunks give the model more to work with but can add noise and slow down small local models. Start with 5; try 8–10 for broad questions. These settings are saved in the current **profile**.

## What's in the Search Context window

The **Search Context** window lets you run a search yourself and see exactly which passages come back.

**Running a search**
1. **Search box** ("Enter search text…"): what to search for.
2. **Number box**: how many results to show.
3. **Search** (magnifying glass): runs the search.

**Comparing methods**
1. **Semantic / Lexical / Hybrid**: switch between methods to compare their results. The results change instantly; there's no need to search again.

**Results**

Each result card shows, from top to bottom:
1. Its rank (**#1**, **#2**…), the document's title, and where the passage is (**Page 4**, **Sheet 2** or **Transcript**).
2. The full text of the passage.
3. Buttons, left to right:
   - **Save chunk** (bookmark with a +): attaches the passage to the open notebook as a source for citations.
   - **Send to notebook** (book icon): adds the passage's text to the open notebook page.
   - **Open document** (arrow out of a box), or **Play this chunk** for audio: opens the original at that spot.

Changes you make in this window don't alter your settings.

## How to

**Change how the chat retrieves**
1. Open **Settings → Agent** and scroll to **Retrieval**.
2. Choose **Semantic**, **Lexical** or **Hybrid**.
3. Set **Retrieved chunks**.

**Search your documents yourself**
1. In **Search Context**, type in **Enter search text…**.
2. Optionally change the number next to it.
3. Click **Search** or press **Enter**.
4. Click **Semantic**, **Lexical** or **Hybrid** to compare the results.

**Let the model search on its own**

Choose **Chat modes → Search**, then turn on the **Tools** button with **Document search** allowed (see **5. Tools**). The model then runs its own searches, chooses the method, and reads neighbouring passages. With **Tools** off, the app runs one search before every reply instead.
