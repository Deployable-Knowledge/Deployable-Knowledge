# 9. Troubleshooting and glossary

| Problem | Try this |
|---|---|
| A window is missing | **Eye** menu → click it |
| The answer ignores my document | Check the document is active in the **Document Library** (its power button). Inactive documents are never searched |
| **Tools** is greyed out | Pick a model that supports tools |
| The model picker says **Select a model**, or says a local model is not downloaded | Download a model under **Local models** and click it to select it (see **8. Settings**) |
| An error mentioning **Ollama** when you send your first question | The app is set to an Ollama model. Pick a **Local model** in the model picker, or install and start Ollama (see **8. Settings**) |
| A file failed to load | Check the type is supported; for synced folders, click **Retry malformed files** |
| Answers are slow | Use a smaller model, lower **Retrieved chunks**, or set **Reasoning effort** to Low |
| Notebook chat with a Local model is slow or gives poor answers | Keep the whole notebook under about 60,000 characters, the recommended maximum for Local models. The **Character count** at the bottom right of the Notebook shows the total across all pages; split a long project into several notebooks |
| A message starting with **/** was sent as plain text instead of running a skill | No skill has that exact name. Type **/** and pick the skill from the list |
| The assistant never uses my skill on its own | Tick **Let the model use this skill on its own** on the skill and **Skills** in **Settings → Tools**, turn on **Tools** in the chat box, and make the skill's description say when it applies. Or run it yourself with **/** |
| "Engine disconnected" banner | Wait a moment; the app reconnects automatically |

**Glossary**
- **Document Library:** the window holding all the documents the assistant can search.
- **Active / inactive:** whether a document is searched. Switch it with the document's power button.
- **Chunk:** a short passage of a document; the unit that search finds.
- **Embedding:** a numeric fingerprint of a chunk's meaning, used by Semantic search. The embedding model downloads automatically the first time you start the app.
- **Retrieval:** finding the chunks that answer a question.
- **Profile:** a saved set of model, prompt and retrieval choices.
- **Skill:** saved instructions you run by typing **/** and the skill's name in chat. The assistant can also use one on its own when a request matches it.
- **Layout:** a saved window arrangement, shown as a tab.
- **Loaded sources:** chunks attached to a notebook, used for citations.

> **You're ready.** Create your own notebook with **+** and start your first project. You can come back to this guide at any time with the **User Guide** button.
